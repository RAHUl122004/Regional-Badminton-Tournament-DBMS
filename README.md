# Regional-Badminton-Tournament-DBM

A DBMS project developed using MySQL to manage regional badminton tournaments, players, matches, sponsors, and rankings.

## Features
- Player Management
- Tournament Tracking
- Match Result Management
- Ranking Analytics
- Sponsor Management
- Tournament Winner Queries
- Stored Procedures and Triggers

## DBMS Concepts Used
- Primary Keys
- Foreign Keys
- Joins
- Aggregate Functions
- Views
- Stored Procedures
- Triggers
- Indexing
- Normalization

## Technologies Used
- MySQL
- MySQL Workbench

## Sample Queries
- Top Ranked Players
- Tournament Winners
- Match History
- State-wise Average Ranking
